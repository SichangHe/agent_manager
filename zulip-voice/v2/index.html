    Keyboard shortcuts

    Space
    play / pause
    ← / →
    previous / next chunk
    Shift + ← / →
    previous / next message
    [ / ]
    slower / faster
    a
    auto-read on / off
    m
    dictate; again: stop and keep text
    Esc
    discard recording; leave the text box
    Enter
    send (in the text box)
    i
    type a reply
    /
    find agent
    Alt + ↑ / ↓
    previous / next agent in the list
    v
    voice control on / off
    ?
    this list
